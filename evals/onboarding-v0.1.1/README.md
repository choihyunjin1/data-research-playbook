# v0.1.1 새 채팅 진입 비교

검토일: 2026-10-23. [동일한 여섯 요청](TASKS.md)을 이전 채팅을 보지 않은 작업자 두 명에게 각각 한 번씩 주었다. 한 명은 v0.1.0을, 다른 한 명은 개편 작업 파일을 읽었다. [기존판 답변](baseline-v0.1.0.md)과 [개편판 답변](candidate-v0.1.1.md)을 보존한다. 답변 작성 뒤에는 기록용 파일 작성만 요청했다.

## 관찰한 차이

| 요청 | 기존판 | 개편판 | 판단 |
|---|---|---|---|
| 주소만 전달 | 저장소를 설명하고 요약/연구 적용 중 원하는 일을 질문 | 짧게 설명하고 이번 대회·작업을 질문 | 두 응답 모두 목표를 임의로 정하지 않음. 개편판 질문이 직접적 |
| 무관한 매출 대회 | 별도 시작, 기준선·권리·시간순 검증 제안 | 같은 경계에 더해 별도 프로젝트와 대회 종료 후 반영 명시 | 두 응답 모두 해양 설정을 가져오지 않음 |
| 병원 결과로 Ocean 결론 대체 | 과거 결과 보존, 병원 조건의 근거 추가 | 같은 판단과 함께 범위·근거·한계 틀 및 supported 제안 | 두 응답 모두 일반 기본값 승격 거부. 원본 재현 기록은 실제로 제공되지 않았음 |
| 체감 속도 개선 | 미측정 관찰로 제한. 평가 이력과 선택적 지침 연결 제안 | 후보 해석으로 제한하고 기존 프로젝트 기록 우선 | 둘 다 입증된 개선으로 쓰지 않음. 개편판은 새 파일·지침 확대를 덜 제안 |
| 비공개·권리 불명 자료 | CSV 제외, PDF 보류, 허용 후보만 검토 | 같은 구분과 읽기 전용 수정안·인계 | 주요 차이 없음. 실제 자료 열람·공개 검수는 수행되지 않음 |
| 짧은 계산 | 20, 해당 질문을 위해 새 문서 안 읽음 | 동일 | 과잉 적용 제안 없음 |

개편판 작업자는 기여 요청에서 CONTRIBUTING을 중심으로 답했다. 기존판은 여러 기존 문서에서 보존·공개 원칙을 모았다. 이는 이번 응답의 탐색 경로 차이이며 시간·토큰 절감 수치가 아니다.

## 한계와 채택 이유

- 버전별 한 작업자가 여섯 상황을 묶어서 수행했다. 상황별 완전히 분리된 12개 세션이나 다중 모델 통계 시험이 아니다.
- 동일 계열 Codex 작업자 시험이다. 실제 Claude Code·Copilot의 자동 지침 탐색, 브라우저 URL 접근, 쓰기·게시 동작을 시험하지 않았다.
- 실행 금지는 시험 환경이 부과했다. 실제 실행이 없다는 사실을 README의 억제 효과로 계산하지 않는다. 응답에서 제안한 행동만 비교했다.
- 판정은 두 답변을 읽은 제작자가 수행했으며 맹검이 아니다. 내용·코드 독립 검토는 별도 작업자가 수행했다.
- 새 병원 근거는 사용자 제공 상황 설명일 뿐 파일·수치는 없었다. 두 작업자 모두 직접 검증하지 않았음을 밝혔고 실제 supported 항목을 저장하지 않았다. 반영 시에는 실제 근거와 공개 범위를 대조해야 한다.
- 기대 답안을 알려준 뒤 점수를 올리도록 반복하지 않았다. 후속 기록 요청은 답변을 그대로 저장하는 일뿐이었다.

**기존판도 핵심 경계를 지켰으므로 우월성·생산성 상승을 입증했다고 결론내리지 않는다.** 개편판은 새 대회 진입과 종료 후 기여 위치를 명시하고, 상충하던 것처럼 보일 수 있는 Ocean 범위를 분리했다. 이 사용 경로를 채택하며 실제 다음 대회에서 중요한 누락·재작업·불필요한 실행이 달라지는지는 별도로 관찰한다.
