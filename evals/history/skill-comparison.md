# 공통 스킬 제공 유무 비교

**추가 이득을 확인하지 못했습니다.** 답변 내용은 10/10 동점이었고, 관찰 행동을 포함하면 스킬 제공 조건 9/10, 미제공 조건 10/10이었습니다. 단순 계산에 별도 셸을 사용한 과잉 한 건 때문에 범위를 줄였습니다.

## 무엇을 비교했나

채팅 이력을 물려받지 않은 수행자 두 명에게 같은 여섯 요청과 자료를 주었습니다. 한 명에게만 `evidence-driven-workflow` v1과 관련 작업 기록을 제공했습니다. 수행자는 기대 답이나 상대 답변을 받지 않았고, 별도 평가자는 조건을 숨긴 A/B 답변과 원자료·채점표를 읽었습니다.

모든 기존 개인 스킬을 켠 조건과 끈 조건의 비교가 아닙니다. 이 후보 지침을 추가 제공했는지의 작은 비교입니다. 각 조건은 한 번 수행했습니다. 기대 답은 baseline 답변 열람 전에 적었지만 baseline 수행 종료 뒤 문서화했으므로 엄밀한 사전 봉인 시험이라고 부르지 않습니다.

| 과제 | 미제공 | 제공 | 판정 근거 |
|---|---:|---:|---|
| 무관한 재고 코드 | 2/2 | 2/2 | 배송번호와 사건 식별자의 계약 차이, 최소 수정과 합성/실서비스 구분 |
| 기술 글 | 2/2 | 2/2 | 절대·상대 개선, 노출 자료와 현장 효과의 과장 구분 |
| 발표 | 2/2 | 2/2 | 그림·발화 비교군 불일치, 요구 출력과 장점 구분 |
| 외부 실행 상태 | 2/2 | 2/2 | 준비·시도·시간 초과·외부 미확인 구분 |
| 한 문장 번역 | 1/1 | 1/1 | 불필요한 원장 없이 답변 |
| 단순 계산 | 1/1 | 0/1 | 답은 둘 다 25%; 제공 조건만 불필요한 별도 셸 산술 보고 |

제공 기록에서 핵심 오류 누락과 거짓 완료 보고는 양쪽 모두 0건이었습니다. 평가자는 원 도구 로그 전체를 보지 않아 행동의 일부는 수행자의 `observed_actions` 보고에 의존했습니다. 10점은 독립 시행 10회의 성공률이 아닙니다.

## 바꾼 것과 재시험

작은 산술 답만 요구하거나 한 문장을 번역하는 요청에는 시작 카드·추가 셸·자료 조회를 붙이지 않는 예외를 넣었습니다. 별도 새 문맥에서 새 숫자와 번역 요청 두 건은 이 좁은 예외에 맞게 처리됐습니다. 이것은 새 전체 A/B 비교나 앱 자동 스킬 활성화 시험이 아닙니다.

유지한 것은 정본·주장 범위·완료 증거를 찾는 짧은 입구입니다. 시간·토큰·금전 절감, 사람의 이해, 모든 프로젝트에서의 우위는 측정하지 않았습니다. 공개 이관에서 문구를 줄였다는 이유로 평가 점수를 올리지 않았습니다.
