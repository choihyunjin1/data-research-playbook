# 과거 평가: 효과가 없었던 결과도 유지

이 폴더는 기존 개발 영역의 2026-10-09 평가를 **공개용으로 요약한 이력**입니다. 새 저장소에서 같은 평가를 다시 실행했다는 뜻이 아닙니다. 원 실행 원문·개인 경로는 공개하지 않고, 요약의 원본 식별자는 [provenance.json](provenance.json)에 남깁니다.

| 질문 | 당시 관찰 | 읽을 문서 |
|---|---|---|
| 공통 스킬을 주면 더 잘하는가? | 핵심 내용 동점. 행동 포함 9/10 대 10/10으로 추가 이득 없음 | [스킬 비교](skill-comparison.md) |
| 작업 지침을 더 강화하면 나아지는가? | 두 새 문맥 쌍 모두 같은 4개 산출물 충족. 증분 이득 미확인 | [추가 개입과 인계](process-intervention.md) |
| 무엇을 고쳤고 무엇은 아직 모르는가? | 합성 입력 계약은 수정·회귀 검사. 자연 작업 생산성·실제 청중 이해는 미측정 | [사건과 근거](incidents.md) |

기존 후보를 선택적 안내로 유지하고, 비슷한 체크리스트를 새 표준으로 늘리지 않았습니다. 현재의 [공개 스킬](../../.agents/skills/evidence-driven-workflow/SKILL.md)은 그 후보의 범위를 줄이고 playbook으로 연결한 이관본입니다. 새 문구의 행동 효과와 자동 선택 성공은 다시 검증된 것이 아닙니다.

테스트 수는 검사 범위이고 문서 수는 산출물 수입니다. 둘을 생산성·모델 성능·과학적 신뢰도의 점수로 합산하지 않습니다. 새 checkout의 실제 실행 상태는 [현재 검수 기록](../../reports/VALIDATION.md)에서 별도로 확인합니다.
