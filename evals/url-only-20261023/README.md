# 실제 URL-only 새 채팅 시험 — 2026-10-23

새 projectless Codex 채팅에 저장소 URL만 보냈다. 채팅은 공개 README를 읽고 작업 목적을 물었으며, 사용자가 승인한 합성 자전거 과제를 이어서 받은 뒤 필요한 지침을 찾아 계산·결론·인계를 작성했다. **한 환경의 1회 재사용 관찰**이며, 모든 AI의 동작이나 README 단독 효과를 입증한 시험은 아니다.

## 시험과 관찰 범위

- 최초 입력은 `https://github.com/choihyunjin1/data-research-playbook` 한 줄이었다. 기존 채팅의 fork가 아닌 별도 projectless 채팅을 썼다.
- 목적 확인 뒤 [후속 과제](task.md)를 전달했다. URL-only 단계 1회와 승인된 과제 적용 단계 1회가 한 시험을 이룬다. 성공할 때까지 반복한 시험이 아니다.
- 당시 참조한 저장소는 [c0551597b5998f73a1c3368d707ae33ac289c311](https://github.com/choihyunjin1/data-research-playbook/tree/c0551597b5998f73a1c3368d707ae33ac289c311) (v0.1.1)이다. 기대값은 후속 전송 전에 별도로 보관했고 대상 채팅에 전달하지 않았다. 사용할 문서 경로·함수·평가표·정답을 코칭하지 않았다.
- 이 문서는 로컬 시험 기록, 실제 계산 코드, 결과표와 인계를 검토해 작성한 공개 요약이다. 원 채팅의 도구 로그·메모리 내용·채팅 식별자·개인 경로는 공개하지 않는다. 외부 독자가 행동 전체를 로그로 감사할 수 있는 완전 공개 기록은 아니다.

| 확인 항목 | 검토한 기록의 관찰 |
|---|---|
| 진입과 목적 확인 | 공개 README를 취득하고 작업 목적을 질문했다. |
| 필요한 지침 탐색 | 고정 커밋의 missing-data, handoff, AGENTS 문서를 읽고 참조 버전을 인계에 남겼다. |
| 타 분야 적용 | 해양 수심·24시간 평균·7일 문맥·해양 보정식은 가져오지 않았다. |
| 계산과 결측 처리 | 합성 입력의 계산 파일을 실제 실행했다. 관측 0을 보존하고 후보가 부족한 D5 이웃 방식의 일총합을 NA로 남겼다. |
| 공정한 비교 | 정확도는 공통 완전 5일, 일총합 산출률은 전체 6일로 분리했다. |
| 결론과 인계 | 선택으로 피한 손해와 놓친 이득을 함께 제시하고, 시간 보간 대비 추가 개선이 없다고 판단했다. 미확인 범위와 다음 행동을 분리했다. |

당시 기록에는 대상 Python 계산이 종료 코드 0으로 완료됐고, 별도 PowerShell 검산과 일치했다고 남아 있다. 같은 기록에서 대상 계산 코드의 별도 재실행 결과 CSV 5개가 원 산출물과 각각 같은 SHA를 보였다고 확인했다. 입력은 24행의 필드가 같았지만 텍스트 바이트 SHA가 달랐으므로, 대상 입력과 최초 입력이 역사적으로 같은 바이트였다고 주장하지 않는다. 이번 공개 준비에서는 새 채팅 시험이나 대상 계산 코드를 다시 실행하지 않았다.

## 합성 입력에서 확인된 수치

하루는 hour 0~3의 네 시간이다. [input.csv](input.csv)는 6일·24행의 합성 대여 건수와 고정 후보 출력이며, `true_count`는 평가용 정답이다. 관측값을 보존하고 빈칸만 채운다. D5 hour 2의 이웃 후보가 없으므로 그 방식의 일총합은 NA이며 부분합이나 0으로 바꾸지 않는다.

| 날짜 | 정답 총합 | 시간 보간 | 이웃 후보 | 고정 choice |
|---|---:|---:|---:|---:|
| D1 | 12 | 12 | 28 | 12 |
| D2 | 92 | 92 | 104 | 92 |
| D3 | 110 | 100 | 110 | 100 |
| D4 | 170 | 160 | 170 | 160 |
| D5 | 52 | 52 | NA | 52 |
| D6 | 18 | 18 | 18 | 18 |

| 비교 범위 | 시간 보간 RMSE | 이웃 후보 RMSE | 고정 choice RMSE |
|---|---:|---:|---:|
| 공통 완전 5일: D1·D2·D3·D4·D6 | 6.324555 | 8.944272 | 6.324555 |
| 전체 6일 | 5.773503 | 산출 불가 | 5.773503 |

RMSE의 단위는 일총합 대여 건수이며 날짜별 가중치는 같다. 일총합 산출률은 시간 보간과 choice가 6/6, 이웃 후보가 5/6이다. choice는 D1·D2의 해로운 보정을 피했지만 D3·D4의 유리한 보정도 모두 놓쳤다. D6에서만 이웃 후보를 골랐으나 두 후보가 같다. 따라서 이번 입력에서 이웃 후보 일괄 사용이나 고정 choice를 시간 보간 대신 채택할 추가 근거는 없었다.

## 공개본 검산과 이관

[독립 검산 코드](independent-check.ps1)와 [기대 집계](expected-results.json)는 당시 검산 파일을 바이트 변경 없이 이관했다. 이 기대 집계는 검산 산출물이지 후속 전송 전에 보관한 기대값 파일 그 자체는 아니다. [provenance.json](provenance.json)에 원본·공개본 SHA와 이관 변환을 구분했다.

저장소 루트의 PowerShell에서 다음 명령은 결과를 표준 출력으로만 내며 파일을 덮어쓰지 않는다.

```powershell
./evals/url-only-20261023/independent-check.ps1
```

출력 JSON의 전체 필드를 `expected-results.json`과 비교한다. PowerShell 버전에 따른 JSON 공백·숫자 표기 차이는 바이트 불일치가 될 수 있으므로 구조와 값으로 대조한다. 공개본 준비 중 이 고정 입력을 재검산해 기존 집계의 전체 필드와 일치함을 확인했다. 이는 기존 산술의 이관 검사이며 새 모델·새 채팅·새 데이터 실험이 아니다.

검산 코드는 **이 고정 24행 입력 전용 예제**다. 스키마·음수·중복·날짜별 시간 구성 등의 범용 입력 검증기는 아니며 다른 자료의 안전한 분석 도구로 승인한 것이 아니다. 원 대상의 더 긴 계산 코드와 자동 생성 보고서는 복사하지 않았다. 실제 후보 생성이나 과거 choice 결정 과정도 검산하지 않는다.

## 남은 한계와 반영 판단

- 새 채팅이지만 계정 공통 메모리와 설치된 스킬을 제거하지 않았고, 대상은 분석 검증 스킬과 산술 서브에이전트도 사용했다. 파일 접근을 물리적으로 격리하지 않았다. 저장소 단독 효과나 기본 모델 능력을 분리하는 대조시험이 아니다.
- 주소만으로 목적 있는 연구를 자동 시작했다는 뜻이 아니다. 사용자 목적과 승인을 받은 뒤 적용했다. 최초 메시지의 화면 표시 방식은 직접 UI 검수하지 않았다.
- 이 6일의 저장 출력 평가는 실제 서비스 효과, 후보·choice의 과거 생성 과정에 누출이 없다는 사실, 다른 날짜·대여소·AI 제품으로의 일반화를 입증하지 않는다. Claude·Copilot, 장기 재사용, 저장소 패키지 설치와 Ocean 재계산은 시험하지 않았다.
- 이번 입력 전용 보고 문구를 임의 입력에 재사용할 수 있다고 결론내리지 않는다. 확인된 재사용 경로의 근거를 추가하되 기존 규칙·README·릴리스의 우월성을 주장하거나 새 필수 체크리스트를 만들지 않는다.
- [과거 onboarding-v0.1.1 비교](../onboarding-v0.1.1/README.md)는 다른 시험으로 보존한다. 이번 실제 새 채팅 관찰을 그 기록에 소급해서 섞지 않는다.
