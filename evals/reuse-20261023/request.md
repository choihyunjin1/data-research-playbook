# 새 작업자에게 주는 요청

공개 저장소 <checkout>의 README부터 필요한 자료를 찾아 다음 일을 수행하세요. 기존 채팅이나 원 연구 폴더는 보지 마세요. 이 디렉터리의 파일과 공개 저장소만 사용하세요.

1. 전력계 데이터를 정리하는 `meter_candidate.py`의 입력 처리와 평균 계산을 검토하세요. 기기 번호는 1~999 사이의 정확한 정수 식별자입니다. 예측값은 0~100 범위로 제한하지만, 비정상 수치(NaN/무한대)는 오류입니다. 시간 평균은 평가 구간 사이에 영향을 주면 안 됩니다. 정상 입력을 보존하면서 필요한 최소 수정안을 별도 파일로 만들고 합성 입력으로 확인하세요.
2. `gap-example.csv`의 한 날짜 중 가운데 6시간 target이 비었다고 가정하세요. 이 파일의 target은 합성 정답이며 방법 입력에 넣기 전에 해당 구간을 가려야 합니다. 시간 보간과 이 저장소의 고정 경계잔차 보정을 비교해 어느 것이 이 사례의 일평균을 더 잘 복원하는지 설명하세요. 전체 자료가 합성이므로 실제 지점 성능을 뜻하지 않습니다.
3. 다른 작업자가 이어받도록 읽은 경로, 실행한 명령, 실제 결과, 미실행 항목, 불필요했던 작업을 한 파일에 기록하세요.

원 자료와 공개 저장소는 읽기 전용입니다. 답변과 수정안은 이 디렉터리 아래 `answer/`에만 저장하세요. 설치·네트워크·Git·게시·모델 학습은 하지 마세요. 사용 가능한 Python은 공개 저장소의 `.venv/Scripts/python.exe`입니다.
