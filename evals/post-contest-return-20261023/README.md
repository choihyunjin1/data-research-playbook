# 대회 종료 후 기록을 되돌려 놓는 절차 시험

2026-10-23, 이전 대화가 없는 독립 작업자에게 합성 종료 패킷과 저장소 사본을 주고 **실제 파일 변경·검산·공개 선택·인계**를 수행하게 했다. 새 결과를 별도 사례로 연결하고, 기존 결과와 공개 보류 자료를 보존했다. 새 스킬이나 공통 필수 규칙을 추가하지 않았다.

## 시험 조건

- 기준: [c0551597b5998f73a1c3368d707ae33ac289c311](https://github.com/choihyunjin1/data-research-playbook/tree/c0551597b5998f73a1c3368d707ae33ac289c311). 원본을 바꾸지 않는 별도 Git 사본에 원격 연결을 제거했다.
- 대상은 새 문맥의 Codex 서브에이전트다. 앞선 [URL-only 시험](../url-only-20261023/README.md)의 사용자 채팅을 이어 쓴 것이 아니다. 동일 계정의 메모리·설치된 스킬·파일 접근은 물리적으로 격리하지 않았고, 대상은 분석 검증 스킬과 독립 산술 작업자도 사용했다.
- [제공 요청·패킷](task.md)에는 새 합성 배치, 근거 없는 속도 개선 주장, 기존 교훈과 겹치는 메모, 공개 권리를 보류한 모의 첨부가 있었다. 실제 고객·비공개 대회 자료는 없다.
- 부모는 기대값을 먼저 고정했으나 작업자에게 정답·평가표·계산 방법을 주지 않았다. README와 기여 절차를 읽으라는 범위 안내는 제공했고, 작업자는 해당 지침과 관련 근거를 직접 읽었다. 첫 수행의 결과를 평가했으며 정답을 알려주고 재시험해 통과시킨 기록이 아니다.
- commit·push·설치·학습은 대상에게 허용하지 않았다. 그러므로 원격 게시 권한 판단이나 보호 브랜치 처리 시험은 아니다. 공개 통합은 결과 인수 후 부모가 별도 수행했다.

## 실제로 반영·보류한 것

| 검토 대상 | 작업자가 남긴 결과 | 부모 대조 |
|---|---|---|
| 새 배치에서 choice가 더 좋은가 | 같은 4일의 총계에서 time MSE 50, neighbor 200, choice 25 | 별도 산술 및 재실행 일치 |
| 과거 Ocean 결과를 바꿀 것인가 | 목표·단위·자료가 다른 새 합성 사례로 추가 | 동결 연구·기존 검증 기록 SHA 보존 |
| 선택기를 모든 작업의 기본값으로 할 것인가 | 합성 저장 출력만으로는 채택 보류 | 공통 코드·기본 설정 변경 없음 |
| 준비시간 40% 단축 | 측정 없는 후보 해석, 성과로 미채택 | 시간·토큰 절감 주장 없음 |
| 같은 날짜·같은 분모 교훈 | 기존 지침에 사례 링크만 추가 | 중복 스킬·규칙 신설 없음 |
| 권리 보류 모의 첨부 | 본문 제외, 상태·사유만 기록 | 공개 파일·stage에 payload 없음 |
| 찾을 수 없는 이전 자전거 시험 | 미확인으로 명시 | 다른 시험으로 대체하지 않음 |
| 준비되지 않은 전체 회귀 환경 | 실패를 그대로 보고 | 새 검사 통과와 전체 실패를 분리 |

새 산술과 적용 범위는 [합성 자전거 사례](../../cases/bike-rental-synthetic/README.md), 첫 수행의 변경·실행·실패 기록은 [사본 인계](../../reports/POST-CONTEST-20261023.md)에 있다. 그 인계의 “게시하지 않았다”와 “전체 회귀 실패”는 **사본 시험 당시 상태**이며 후속 공개 상태로 덮어쓰지 않았다.

## 실제로 막힌 곳과 후속 보완

1. **의존성 부족:** 대상의 Python에는 pandas가 없어 전체 회귀는 18개 검사 통과와 2개 import 오류로 실패했고 demo도 실패했다. 설치 금지를 지켰다. 부모는 이미 의존성이 준비된 저장소 환경에서 같은 코드를 실행해 **68개 검사와 demo 통과**를 확인했다. 첫 실패 기록은 그대로 남겼다.
2. **최신 근거 연결 누락:** 사본 기준 커밋에는 이전 자전거 시험이 아직 없었다. 부모가 두 시험을 함께 이관하며 사례에 “공개 통합 후 연결” 문단을 추가했다. D 배치에서는 choice가 time을 개선하지 못했고, E 배치에서는 개선했다. 서로 다른 합성 입력이므로 알고리즘의 개선 전후가 아니다.

나머지 기여 규칙은 이번 관찰에서 필수 수정 근거가 발견되지 않아 늘리지 않았다. 모의 첨부는 의도적으로 권리를 보류한 직접 작성 문자열이다. 실제 제3자 권리 판단 능력을 입증하는 시험은 아니다.

## 보존과 공개 통합

- 사본의 신규 6개 파일과 기존 지침·공개 메타데이터 3개, 총 9개 경로를 검토했다. 기존 133개 추적 파일 중 허용 변경 3개를 뺀 **130개 SHA가 모두 일치**했다.
- 부모 통합에서는 README·CONTRIBUTING의 시작 링크, 지침의 사례 연결, 현재 공개 목록·manifest만 기존 파일에서 변경했다. 나머지 **128개 기존 파일 SHA가 모두 일치**했다. Ocean 결과, 과거 `evals/`·`reports/`, 기존 스킬·코드와 릴리스 설명은 보존했다.
- 원래 사본의 inventory·manifest는 통합본으로 복사하지 않고, 새 공개 파일을 개별 검토한 뒤 전체 현재 목록을 다시 만들었다. 내용 검토와 SHA 검사는 별개다.
- [검증 기록](verification.json)에 입력·인계 식별자와 첫 실패/후속 성공을 분리했다. 이 문서는 공개 Git에 들어간 시험 요약이며 완전한 도구 로그는 아니다. 개인 경로·채팅 식별자·제한 모의 본문은 제외했다.
- 기존 `v0.1.0`·`v0.1.1` 태그와 릴리스 자산은 변경하지 않는다. 이번 시험 기록 추가를 기존 릴리스에 소급하지 않으며 별도 새 릴리스는 만들지 않았다.

## 해석 범위

이번에 확인한 것은 **한 환경에서 종료 패킷을 실제 변경으로 옮기고, 적용 범위와 보류 상태를 유지한 경로**다. 실제 대회가 종료된 사례, 사람의 사용성, 모든 AI 제품, 생산성 향상, 지침의 인과 효과는 검증하지 않았다. 공개 집계 재현도 과거 작업자의 모든 행동을 증명하는 것은 아니다.

다음 실제 대회에서는 해당 프로젝트에서 얻은 기록으로 같은 절차를 적용할 수 있다. 그때도 현재 저장소 주소를 읽었다는 사실만으로 쓰기·공개 권한이 생기지 않는다. 기여 규칙의 정본은 [CONTRIBUTING.md](../../CONTRIBUTING.md)이며 이 시험을 새 필수 체크리스트로 쓰지 않는다.
