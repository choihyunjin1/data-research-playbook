# 근거를 이어가는 작업

기존 공통 스킬의 공개 이관본이다. 사용자 요청과 프로젝트 지침을 우선하며 새로운 작업 권한이나 승인 단계를 만들지 않는다. 단순 번역·짧은 계산에는 이 절차를 붙이지 않는다.

현재 결과와 변경 범위가 명확하면 다시 묻지 않는다. 진행 확인 요청을 새 실험으로 바꾸지 않는다. 이번 요청에 맞는 경로만 읽는다.

- 입력·코드의 반례와 회귀: [코드 계약](../../../playbooks/code-contracts.md).
- 선택 자료·비교군·가림과 관측 지원: [결측 자료 분석](../../../playbooks/missing-data.md). 해양 방법을 다른 분야의 기본값으로 강제하지 않는다.
- 주장·그림·대본이 같은 비교를 설명하는지: [결과 전달](../../../playbooks/communicating-results.md).
- 현재본·재시도·실제 완료와 외부 반영: [인계](../../../playbooks/handoff.md).
- 다른 공모에 자료를 다시 쓰는 경우만: [새 대회 검토](../../../playbooks/new-competition.md).

위 문서가 규칙의 정본이다. 같은 수치·지침을 별도 원장에 반복 복제하지 않는다. 관련 없는 전체 이력이나 전체 테스트를 시작 조건으로 요구하지 않는다.

[기존 효과 평가](../../../evals/history/README.md)는 이 스킬의 보편적 우위나 시간 절감을 입증하지 못했다. 이번 공개용 경로 정리는 새로운 행동 효과 검증이 아니다. 작업을 방해하거나 결과를 바꾸지 않는 규칙은 실제 관찰을 근거로 축소한다.
