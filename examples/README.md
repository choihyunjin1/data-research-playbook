# 원자료 없이 시작하기

`python -m research_playbook demo`는 실제 자료가 아닌 창고 번호·전력계 예제로 세 가지 계약을 보여줍니다.

| 질문 | 사용할 함수 | 놓치기 쉬운 반례 |
|---|---|---|
| 창고 번호를 정수로 바꿔도 되는가? | `exact_integer` | `2.9`를 먼저 int로 바꾸면 잘못된 2를 받음 |
| 예측값을 0~100으로 제한해도 되는가? | `finite_clip` | Inf를 먼저 clip하면 겉보기 정상값 100이 됨 |
| 평균에 다른 평가 구간이 섞이는가? | `boundary_mean` | 학습 구간 옆 검증값 100이 학습 평균에 들어감 |

세 함수는 입력 오류와 비교 경계를 검사합니다. 실제 재고 시스템·전력 예측 모델의 성능을 검증한 예제는 아닙니다.

해양 방법을 보려면 [고정 연구 사례](../cases/ocean-gap-repair/README.md)를 읽으세요. 공백 뒤 관측을 사용하는 방식이므로 실시간 예측과 구분합니다.
