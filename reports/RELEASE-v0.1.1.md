# v0.1.1 — 새 채팅 진입과 종료 후 지식 반영

## 달라진 점

- README에서 주소만 받은 경우와 새 대회 공고를 받은 경우의 시작 경로를 구분했다.
- 새 대회는 별도 프로젝트에서 진행하고 종료 후 검증된 교훈만 일괄 반영한다.
- CONTRIBUTING에 후보·확인된 범위·정정·공개 검토·권한 있는 자동 반영 절차를 모았다.
- Ocean 종료 연구의 제한을 사례로 한정하고 Claude Code·Copilot 연결 파일을 추가했다.
- 공개 파일 목록의 누락·중복·빈 검토를 검사하는 CLI와 회귀 검사를 추가했다. 권리 인증 도구는 아니다.

## 유지한 것

`demo`와 `replay` 인터페이스, 연구 알고리즘·설정·집계, v0.1.0 보고서와 릴리스는 보존한다. 새 모델 학습·원자료 재계산·방법 개선을 수행한 릴리스가 아니다.

## 검증 범위

[검수 기록](VALIDATION-v0.1.1.md)과 [새 문맥 비교](../evals/onboarding-v0.1.1/README.md)를 확인한다. 기존판도 주요 경계를 지켰다. 문서 개편의 보편적 생산성 효과나 실제 Claude·Copilot 동작을 입증한 것은 아니다.

원격 커밋·태그·다운로드한 자산·CI 검증은 게시 후 추가하는 릴리스 자산 `external-verification-v0.1.1.json`에 기록한다. 이 릴리스 설명만으로 외부 보존 완료를 주장하지 않는다.
