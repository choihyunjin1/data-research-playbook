새 inventory 검사는 추적 파일별 공개 선정 항목과 설명 유무를 검사한다. 항목 자체와 `PUBLIC_MANIFEST.json`도 목록 대상이다. 내용이 실제로 공개 가능한지는 별도 원문 검토이며, 변경 파일의 수동 재검토를 절차에 명시했다. 새 경로 누락·중복·미확인 설명·위험 경로·깨진 JSON·삭제 파일과 읽기 전용 동작을 테스트했다. symlink 거부 분기는 구현했지만 플랫폼별 직접 생성 시험은 이번 10개 검사에 포함하지 않았다.

## 과장하지 않는 범위

- 원자료 재계산·모델 학습·방법 선택 재실험은 0회. v0.1.0의 원자료 재현 기록을 이번에 새 실행한 것으로 옮겨 쓰지 않는다.
- 공식 문서는 지침 인식 설계의 근거다. 실제 Claude Code·Copilot 앱의 자동 인식은 미시험이며, URL 브라우징도 독립 사용 시험의 범위 밖이다.
- 문서 비교는 한 번씩 수행했고 시간·토큰·장기 생산성을 측정하지 않았다. 후보 작업자는 발행 전 파일을 읽었으며, 뒤의 가벼운 문구 정리와 검수 기록 추가를 별도 행동 재시험으로 세지 않는다.
- 공개 목록과 manifest의 최종 전체 대조는 CI에서도 수행한다. 원격 CI·기본 브랜치·태그·자산 다운로드 결과는 게시 후 릴리스 자산 `external-verification-v0.1.1.json`에 연결한다. 이 문서의 로컬 PASS만으로 공개 완료를 판정하지 않는다.

당시 v0.1.0 태그 커밋은 `ab3a7147fa54ff3558d9922d6be0b5bc7c3f8fd0`이다. 과거 release 자산과 태그는 수정하지 않는다. 원자료의 다른 장치·클라우드 백업 미완료 상태도 그대로 유지한다.
