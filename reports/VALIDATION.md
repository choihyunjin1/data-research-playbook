원본 노트북의 당시 출력은 수정하지 않았습니다. 화면 검토는 저장 출력의 HTML 렌더이며 네이티브 Jupyter 앱에서 재실행한 것은 아닙니다. 최신 연구의 원본 README에 남아 있던 시각 검수 미완료 상태를 이 공개 이관 기록에서 마무리합니다.

## 공개 전 수정한 사항

1. CI가 base 의존성만 설치해 replay 검사를 import하지 못할 조건을 독립 검토에서 발견했습니다. CI는 `[replay]` 의존성을 설치합니다.
2. 원자료 재계산 설명에서 제공기관의 시간 집계·QC까지 재실행한 것처럼 읽히는 문구를 바로잡았습니다. 이미 시간 집계된 제품을 추출해 이후 계산을 재현합니다.
3. 원본 해시·고정 설정의 바이트가 운영체제의 줄바꿈 변환으로 달라지지 않도록 Git 자동 변환을 끕니다.
4. 일반 평균 함수가 pandas rolling의 창 경계와 다르다는 독립 재사용 관찰을 문서와 회귀 검사에 반영했습니다.

## 별도로 확인하는 항목

깨끗한 clone 실행, 원본 전후 확인, 파일별 공개 선정은 [기계 판독 상태](validation.json)에 기록합니다. 원격 저장소·태그·릴리스와 자산 다운로드 확인은 게시 후 릴리스 자산 `external-verification.json`으로 남깁니다. 게시 전 이 문서 자체가 외부 보존 완료의 증거는 아닙니다.

Python 3.12 source checkout + editable 설치가 지원 경로입니다. wheel 단독 설치, 임의 장비의 원자료 수치 재현, 실서비스 성능, 제공기관 QC 재생성, 기존 공통 스킬의 추가 효과는 이 검수의 통과 범위가 아닙니다.
