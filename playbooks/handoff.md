# 다음 사람이 다시 찾지 않아도 되는 인계

## 남길 것은 현재 판단에 필요한 것

1. **현재본:** 파일 또는 커밋과 해당 입력·설정. ‘최신’이라는 이름만 남기지 않습니다.
2. **실행 범위:** 어떤 명령이 어떤 결과를 만들었는지, 종료와 실제 출력이 연결된 receipt.
3. **완료 축:** 합성 검사, raw 재계산, 수치 대조, 내용·화면, 외부 반영을 따로 기록.
4. **다음 행동:** 미확인 한 가지와 그것을 구별할 작업. 이미 끝난 이력을 모두 다시 읽거나 실행하도록 넘기지 않습니다.

[기존 인계 시험](../evals/history/process-intervention.md)에서는 새 문맥 작업자가 최소 운영 입구를 따라 정상 합성 출력과 잘못된 식별자 거부를 확인했습니다. 이것은 로컬 경로를 발견한 증거이지, 다른 사람의 장기 생산성이나 자동 스킬 선택을 검증한 결과가 아닙니다.

## 재시도가 필요할 때

`마지막 관찰 / 실패한 단계 / 이번에 바뀐 조건 / 기대하는 새 관찰`을 먼저 구분합니다. 이전과 같은 상태를 다시 확인할 이유가 없다면 같은 실행을 반복하지 않습니다. 외부 저장·발송이 시간 초과였다면 실제 반영 여부부터 확인하고 중복을 막습니다.

준비, 버튼 클릭, 서버 저장, 공개 URL 확인, 운영진 접수는 다른 상태입니다. 사용자 피드백으로 요구가 바뀐 것은 실패 재시도와도 다릅니다. 버전 수만으로 낭비 시간을 계산하지 않습니다.

## 원본 보존과 공개 이관

원본 파일의 해시와 공개용 변환 파일의 해시는 다릅니다. 경로 제거·요약·이름 변경을 했다면 변환 내역과 원본 식별자를 남깁니다. 이관 시 만든 지문을 당시 실험의 사전 고정 기록처럼 설명하지 않습니다.

복구 패키지는 별도 위치에 실제로 풀어 목록·크기·해시를 대조합니다. 같은 디스크의 로컬 복구 패키지와 다른 장치의 백업을 구분합니다. release도 태그의 원격 커밋과 실제 내려받은 자산을 확인해야 합니다. 둘 모두 연구 방법의 우수성을 증명하는 검사는 아닙니다.
