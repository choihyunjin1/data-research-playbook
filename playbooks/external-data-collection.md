# 외부 자료를 모으는 작업의 완료 단위

가격·카탈로그처럼 외부 자료를 모을 때 적용한다. [SaveTax 사례](../cases/savetax-crawler/README.md)에서는 도구와 전량 품목 CSV를 만들었지만 전량 비교가격이나 점수 등록을 확보하지 못했다. 수집 대상을 늘리기 전에 어떤 단위가 늘어야 목적을 달성하는지 정한다.

## 무엇이 늘었는지 나누기

| 계수 | 확인한 것 | 아직 증명하지 못한 것 |
|---|---|---|
| 원본 품목 행 | 목록의 누락·중복·고정 순서 | 외부 출처 확보 |
| 판매상품/요청/응답 | 판매처 탐색 범위와 수집량 | 조달 품목과의 연결 |
| 가격 관측 | 특정 시각·원문 위치의 금액 | 숫자의 역할·동일 구성·현재 구매 가능성 |
| 유효한 상품 연결 | 품목과 출처의 동일성 근거 | 세금·배송·설치·수량·보증·시점의 비교 가능성 |
| 비교 가능 가격 | 필요한 조건을 갖춘 비교 단가 | 제출 적격성·선점 가능성·최종 인정 |

전환율은 분자·분모가 연결되는 같은 코호트와 명시한 관측기간으로 계산한다. 시점·정의가 다른 스냅샷 수치를 바로 나누지 않는다. `complete=true`는 manifest의 산출물 범위가 끝났다는 뜻으로 제한한다. 가격이 없거나 조건이 불명확하면 공란과 이유를 보존하고 정상 가격으로 판정하지 않는다.

## 원문과 상품 연결을 분리하기

URL 원문·수집 시각·해시·관측 이력과 `품목 ↔ source` 연결은 다른 개체다. 두 품목이 같은 URL을 참조할 때 한 연결이 틀렸다고 URL 전체를 삭제하면 다른 품목의 유효 근거도 사라진다. 연결 단위로 보류하고 대표값·검색·모델 검토에서 제외하되 원문과 감사 이력은 보존한다.

최신 상태를 나타내는 판매처 목록에서는 최신 관측의 가격이 미확인이면 이전의 숫자로 조용히 채우지 않는다. 과거 가격은 시각이 붙은 이력으로 보여 줄 수 있다. 모든 도메인의 결측 보완 금지가 아니라 **현재 판매상태를 주장하는 산출물**의 조건이다. [합성 반례](../cases/savetax-crawler/synthetic_replay.py)는 이 경계를 재현한다.

모델 접미사·세대·용량·부품 역할·묶음 구성은 작은 문자열 차이여도 다른 상품일 수 있다. 목록의 정확 모델명과 상세 규격·판매 조건 확인을 분리한다. 검색 결과·JSON-LD·본문 판매가·배송비·할부금을 하나의 가격으로 합치지 않는다. 실패 원문을 재요청하기 전에 저장 응답으로 추출기를 재검증한다.

## 정체를 고치기 전에 실패 단위를 찾기

프로세스와 health가 살아 있어도 요청·새 관측·유효 연결이 늘지 않을 수 있다. 마지막 완료 요청과 후보별 대기 이유를 보며 로컬 스케줄러 병목, 무료 예산 소진, 적격 후보 없음, 접근 거부를 구분한다. 최근 확인 시각은 작업 진척이 아니다.

후보 건너뛰기를 개선하더라도 실제 HTTP 예약에서만 사용량·요청 순서 커서를 바꾸고 호스트 간격·공용 예약·실패 이력을 유지한다. 이 커서는 사례의 요청 배분 상태이며 응답에서 받는 페이지네이션 커서가 아니다. 접근 거부나 종료된 API를 재시작으로 고치려 하지 않는다. 서비스 변경에는 정상 drain과 필요한 상태 지문을 확인한다. 숫자로 정한 정책값은 당시 환경 조건이며 다른 사이트에 그대로 이식하지 않는다.

요청 처리량 개선 후에는 새 고유 상품·새 가격·유효 비교의 증가를 별도로 잰다. 수율이 0이면 한도 확대가 조사 성과를 늘린다는 근거가 없다. 서로 다른 표본의 짧은 처리량으로 전량 완료 날짜를 예측하지 않는다.

## 제출 가능한 소량부터 확인하기

제출 자격·중복/선점 여부·필수 사실·단위·세금·납품 범위를 작은 표본에서 먼저 확인한다. 현장설치 포함 조달 단가와 배송만 하는 본체 판매가는 자동으로 같은 조건이 아니다. 설치비를 0원으로 두거나 무관한 상품의 설치비를 대신 더하지 않는다.

더 일찍 적용했으면 얼마나 시간을 절약했을지는 측정하지 않았다. [새 대회 시작](new-competition.md)의 자격 확인에 이번 반례를 연결하며 새 필수 대형 절차로 만들지 않는다. 미리보기·접수·최종 인정의 차이는 [인계](handoff.md)의 기존 기준을 적용한다.
