# 작업별 길찾기

먼저 해결하려는 문제와 맞는 문서 **하나**를 고릅니다. 짧은 번역·문구 수정·계산에 별도 원장이나 전체 검사를 붙이지 않습니다.

| 상황 | 확인할 판단 | 문서 |
|---|---|---|
| 새 분야의 대회를 시작하거나 이전 연구를 쓰고 싶다 | 요구 결과, 첫 비교, 자료 권리, 도구 요건이 맞는가 | [새 대회](new-competition.md) |
| 공백을 채우면 통계가 좋아질 것 같다 | 강한 기준선·같은 분모에서도 좋은가 | [결측 자료](missing-data.md) |
| 정상 입력은 돌아가지만 결과가 불안하다 | 변환이 잘못된 입력을 정상처럼 만들고 있지 않은가 | [코드 계약](code-contracts.md) |
| 수치가 맞는데 글이나 발표가 납득되지 않는다 | 무엇이 달라졌는지 그 그림과 문장이 답하는가 | [결과 전달](communicating-results.md) |
| 다른 사람·AI가 이어서 일해야 한다 | 현재 파일, 실제 검사, 미완료가 연결되는가 | [인계](handoff.md) |
| 대회가 끝나 새 교훈을 반영한다 | 실제로 바뀐 판단과 공개 가능한 근거가 있는가 | [기여 절차](../CONTRIBUTING.md) |

이 문서들은 [실제 사건 요약](../evals/history/incidents.md)과 [효과 비교](../evals/history/README.md)를 토대로 정리했습니다. 지침이 존재한다는 사실만으로 재발 방지 효과를 인정하지 않습니다. 새 작업에서 놓친 오류·중요한 재수정·불필요 실행이 달라지는지 관찰하고 도움이 없는 부분은 줄입니다.
