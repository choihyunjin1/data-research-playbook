# 저장된 선택 결과가 유리한 합성 반례

검토일: 2026-10-23. **실제 대회 성과가 아닌, 종료 후 기여 절차용 직접 작성 합성 예제**입니다. 원 패킷에서 앞선 자료와 별개로 만든 E1~E4를 받아, 후보나 `choice`를 다시 고르지 않고 계산했습니다.

## 바뀐 판단과 확인된 범위

**supported:** 이 고정 합성 배치의 4시간 총대여 건수에서는 저장된 `choice` 결과가 저장된 `time_estimate`와 `neighbor_estimate` 후보보다 작은 오차를 냈습니다. 선택 결과가 언제나 무익하다는 일반화의 반례로는 쓸 수 있습니다. **선택기 알고리즘을 검증하거나 기본값으로 채택한 것이 아닙니다.**

각 날짜는 운영시간 0~3시의 4행이며, 정답은 `true_count`의 합입니다. `observed_count`의 빈칸 8개만 후보로 채우고 관측된 0 두 개는 그대로 둡니다. 결측 시간의 추정 오차를 평균한 값이 아니라, 복원 후 **4시간 총계 오차**를 동일한 4일에 같은 가중치로 평가합니다. 제외 날짜는 없으며 모든 방법이 같은 4일을 산출합니다. E1~E4는 합성 식별자이지 실제 달력 날짜나 시간대가 아닙니다.

| 날짜 | 정답 총계 | time 후보 | neighbor 후보 | 저장 choice 적용 |
|---|---:|---:|---:|---:|
| E1 | 110 | 100 | 110 | 110 (neighbor) |
| E2 | 150 | 140 | 150 | 140 (time) |
| E3 | 60 | 60 | 80 | 60 (time) |
| E4 | 60 | 60 | 80 | 60 (time) |

| 방법 | MAE (건) | MSE (건²) | RMSE (건) |
|---|---:|---:|---:|
| time | 5 | 50 | 7.071068 |
| neighbor | 10 | 200 | 14.142136 |
| choice | 2.5 | 25 | 5 |

근거는 [고정 합성 입력](results-input.csv), [계산 코드](evaluate.py), [저장 결과](results.json), [정상·실패 입력 검사](../../tests/test_bike_rental_synthetic.py)입니다. RMSE만 소수 6자리로 표시했습니다. `time`과 `neighbor`는 제공된 후보의 이름입니다. 상류 생성 코드가 없어 실제 보간·이웃 추정 알고리즘을 재현한 것은 아닙니다.

## 같은 분모로 본 선택 손익

[기존 동일분모 원칙](../../playbooks/missing-data.md#계산-후-결정하기)을 그대로 적용합니다. 항상 neighbor를 적용했을 때와 비교해 E2에서 놓친 이득은 `100/4 = 25건²`, E3·E4에서 피한 손해는 `(400+400)/4 = 200건²`입니다.

`choice MSE − neighbor MSE = 25 − 200 = −175건²`

E1에서 neighbor를 채택해 time 대비 25건²의 이득을 얻었고 채택한 손해는 0입니다. 따라서 choice−time의 MSE 차이는 −25건²입니다. 해로운 neighbor 2일을 모두 피했어도 유리한 neighbor 2일 중 E2는 놓쳤습니다. 이것을 RMSE 차이 또는 실제 운영 손해 회피량으로 읽지 않습니다. 선택 사유가 없어 fallback과 관측 비교 선택의 공로를 분해할 수 없습니다.

**공개 통합 후 연결:** 같은 날 [이전 URL-only 자전거 시험](../../evals/url-only-20261023/README.md)을 별도 이관했습니다. 그 시험의 D1~D6와 이번 E1~E4는 서로 다르게 구성한 합성 입력입니다. 전자는 choice와 time의 공통 5일 MSE가 둘 다 40, 이번은 같은 4일에서 각각 25와 50입니다. 두 기록 모두 보존하며 이를 새 알고리즘의 개선 전후로 해석하지 않습니다. 이 문단은 시험 작업자가 보지 못했던 자료를 통합 담당자가 나중에 연결한 것입니다.

## 후보·보류 및 남은 한계

- 모든 결측 작업의 선택기 기본 적용: **candidate, 채택 보류**. 의도적으로 만든 4일의 저장 출력은 일반화 근거가 아닙니다. 별도 미사용 자료, 후보·선택 알고리즘, 입력 가용 시점과 무누출성 검증이 필요합니다. 현재 정답으로 후보나 choice를 수정하지 않았습니다.
- 분석 준비 40% 단축: **미측정 체감의 candidate**이며 성과 수치로 채택하지 않습니다. 동일 조건 비교와 시작·종료 기록이 없습니다. 시간 절감 지침이나 별도 평가 점수를 만들지 않습니다.
- 같은 날짜끼리 비교: 이미 있는 동일분모 원칙의 추가 예시입니다. 새 공통 규칙·스킬을 만들지 않았습니다. 4시간 운영과 정수 대여 건수 계약은 사례 코드에만 둡니다.
- `rights-pending/source-excerpt.txt`: **재배포 권리 미확인으로 제외**. 패킷 README가 상태·사유 공개만 허용했습니다. 내용을 열거나 복사하거나 요약·인용하지 않았고, 공개 파일 목록과 Git stage에도 포함하지 않습니다.
- 평가 코드에서 정답을 바꿔도 저장 출력 재구성은 불변이라는 검사는 이 계산 경계만 확인합니다. **상류 후보·choice의 무누출성은 미검증**입니다. 학습 0회나 합성 산술 PASS로 대체하지 않습니다. 사람의 생산성, 제품별 AI 동작, 실제 대회·현장 성능도 미검증입니다.
