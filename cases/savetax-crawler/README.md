# SaveTax 조사: 가격 검증보다 먼저 갖춰진 수집 도구

2026-10-23 프로젝트 종료 시점의 회고다. 요청 이력·예산·호스트 간격을 보존하며 저장 원문을 다시 읽고, 잘못된 상품 연결을 격리하고, 전체 품목 스냅샷을 내보내는 로컬 수집 도구를 만들었다. **전량 외부 시장가격 검증이나 점수 등록 성과는 확보하지 못했다.** 도구의 구현과 조사 목적의 달성을 분리한다.

저장소 기준은 `d28017258531bae2611e2e00f0af3f2183c320ab`이다. 기존 연구·합성 비교·당시 검증 기록은 바꾸지 않았다. 교훈의 본문은 [외부 자료 수집](../../playbooks/external-data-collection.md)에 두고, 여기에는 근거와 적용 한계를 남긴다.

## 바뀐 판단과 확인된 범위

수치는 [선별 집계](evidence-summary.json)의 `historical_measurements`에 연결된다. 아래 판단은 `supported`이며 해당 관측·입력 범위만 지지한다.

| 바뀐 판단 | 근거 | 남은 한계 |
|---|---|---|
| 전량 CSV와 전량 가격 검증은 다르다 | `inventory_snapshot`: 19:51 KST 스냅샷은 987,050행, 대표 외부 관측 541품목, 관측 long 12,730행. 누락·추가·중복·순서·500개 묶음 오류 0 | 대표 관측에는 검색 표시·본문 숫자·구조화 가격이 섞인다. 동일 상품·설치·재고·세금 조건이 검증된 가격 수가 아니다 |
| 요청 수 증가가 새 가격 증가를 보장하지 않는다 | `scheduler`: 과거 300요청 창은 분당 8.94회, 수정 직후 32요청은 첫·마지막 요청 간 분당 24.54회. 직후 32개는 성공했으나 반환 상품 0개 | 표본·시간창·검색어가 다른 비무작위 관측이다. 약 2.7배의 가격 생산성 향상이나 전량 완료 ETA로 환산하지 않는다 |
| 로컬 대기 병목과 접근 한도는 다르다 | 출처가 이미 충분한 후보 21개가 각각 서비스 대기를 소비했다. 한 step에서 최대 32개를 기존 deferred 상태로 넘기는 수정 후에도 실제 예약에서만 cursor가 증가하고 호스트 간격·예산·실패 hold를 유지했다 | 전체 운영 스케줄러를 이 저장소에 이식하지 않았다. 숫자 32·60초·2초는 당시 구현 조건이지 권장 기본값이 아니다 |
| 잘못된 연결을 끊어도 공유 원문은 보존해야 한다 | `closeout`: 연결 격리 63개. URL 원문·관측 이력과 품목-source 연결을 분리했다. 아래 합성 반례가 공유 URL의 한쪽 격리와 최신 미확인 값을 재현한다 | source 활성은 상품 동일성·현재 구매 가능성의 판정이 아니다. 모든 과거 출력의 대표가격 정책이 같다는 주장도 아니다 |
| 살아 있는 서비스와 진행 중인 조사는 다르다 | 실제 프로세스·health·status와 새 요청/관측 증가를 따로 확인했다. `restart`: 재시작 전후 선정한 11개 상태 지문이 일치했다 | 상태 파일·PID 문자열만으로 새 자료 확보를 증명하지 않는다. 전체 파일 시스템 보존 검사도 아니다 |
| 미리보기 통과는 적격성·접수가 아니다 | `registration_screening`: 선정 후보 79개 중 70개 등록 불가, 9개 가능 표시, 실제 점수 제출 0개. 한 후보는 산술 미리보기 통과 후 원본의 현장설치 조건 때문에 보류했다 | 전체 품목의 등록 가능률이 아니다. 설치 없는 본체가격으로 같은 납품 조건을 주장하지 않았다 |

종료 직전에는 사용 가능한 판매처 근거가 있는 품목 379개, 세부 관측 524건, 검증 비교 0건이 기록됐다. **더 이른 541품목 대표 관측과 시점·선정 기준이 다르다.** 541→379를 같은 시점의 검증 전환율로 계산하지 않는다.

## 공개한 재현과 비공개 원본

[synthetic_replay.py](synthetic_replay.py)는 직접 작성한 가짜 식별자·가격·URL을 쓰는 메모리 SQLite 예제다. [계약 검사](../../tests/test_savetax_crawler.py)는 공유 URL 연결 격리, 최신 가격 미확인, 고정 순서와 누락·중복을 확인한다. 실제 크롤러·사이트 파서·가격 비교 모델을 배포한 것이 아니다. 예제의 비교 가능 상태는 합성 fixture가 부여한 조건이며 실제 상품 검증 결과가 아니다. 예제는 품목당 판매처 연결 하나와 합성 시각 tick만 다루며, 검색·모델 검토 큐나 다중 판매처 대표값 정책은 재현하지 않는다.

```text
python cases/savetax-crawler/synthetic_replay.py
python -m unittest discover -s tests -p test_savetax_crawler.py -v
```

이 실행은 과거 HTTP 응답, 987,050행, 처리량 관측이나 대회 결과를 재현하지 않는다. 원프로젝트의 관련 계약 검사와 공개 합성 예제 검사는 [이번 검증 기록](../../reports/VALIDATION-v0.2.0.md)에서 분리한다.

공개 집계는 직접 작성한 운영 기록의 허용 필드만 새 JSON으로 옮겼다. 원본 basename과 SHA는 `private_evidence_fingerprints`에 남겼지만 원본 payload는 포함하지 않았다. 지문은 로컬 원본 대조용이며 외부 감사 인증이나 제3자가 과거 수집을 재현할 수 있다는 보증이 아니다.

## 공개 권리와 보류

조달 자료 출처는 조달청 나라장터 공개 정보, 데이터셋 가공자는 50trillion이다. 사용한 자료 버전은 `20261010-r5`다. 2026-10-23 [데이터셋 제공처](https://savetax-dataset.reform-dev-infra.workers.dev/)의 공식 이용 조건을 무인증 HTTP 200 응답으로 다시 확인했다. 원본 재배포를 금지하고 출처를 밝힌 분석 결과·코드 공개를 허용하며, 대회 후 다른 자료 이용은 운영진 문의 대상으로 둔다. 조회일·URL·응답 SHA는 [권리 확인 기록](evidence-summary.json)의 `public_rights_check`에 있다. [공식 안내](https://hackathon.savetax.now/#/data)도 참조한다. 이번 변경은 기존 조사의 방법·직접 작성 집계이며 원자료를 다른 연구에 재사용하지 않는다.

- 조달 원본·전량 가격 CSV·판매처 HTML·이미지·규격서·계정 화면·인증정보는 제외했다. 열람 가능성을 재배포 허락으로 바꾸지 않았다.
- 사이트별 adapter를 포함한 운영 수집기 전체는 외부 의존성·권리·서비스 설정의 별도 공개 검토 전까지 로컬 보존한다. 이 사례 코드는 수집기 전체가 아니다.
- AI 모델 추가에 따른 정확도·생산성 개선, 장기 처리량, 단기간 전량 수집 가능성, 사용자 재사용 효과는 미검증이므로 기본 권고로 올리지 않았다.
- 종료 때 자동 확인 예약을 삭제하고 요청 drain 확인 후 정상 종료했다. 이 저장소에는 새 수집·등록 hook을 넣지 않았다.

`corrected` 관계는 도구 구현·CSV 행 확보·서버 산술 검사만으로 검증 가격·실제 등록을 얻었다고 볼 수 없다는 설명에 적용한다. 이전 기록은 보존한다. 더 이른 자격 확인이 시간을 얼마나 절약했을지는 `candidate` 해석이며 측정된 효과가 아니다.
