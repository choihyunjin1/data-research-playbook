# 수온의 빈칸을 채우면 하루 평균도 더 정확해질까?

공개 해양 수온 자료에서 남은 관측 평균, 시간 보간, 수심 보간과 경계잔차 보정을 비교한 연구입니다. **더 많은 정보를 사용하는 보정이 언제나 유리하지 않았고, 주변 관측으로 보정 여부를 고르는 규칙도 보편적인 우위를 보이지 않았습니다.**

제한된 Ocean 대회 자료·신경망·답안을 가져온 연구가 아닙니다. KIOST 이어도와 IMOS의 별도 공개자료를 사용했고 모델 fitting은 0회였습니다. 자료를 보고 방법을 고안한 탐색과 새 자료를 보기 전 고정한 시험은 구분합니다.

## 읽는 순서

1. [최종 결론](CONCLUSIONS.md): 어떤 성과가 있고 무엇은 채택하지 않았는가.
2. [아홉 단계의 이력](HISTORY.md): 질문·고정 조건·실패·다음 판단.
3. [자료와 권리](SOURCES.md): 공식 원본, 버전·파일 SHA, 가공 내용.
4. [제출 상태](submission-status.md): 공개 연구와 KDATA 접수는 별개.

## 무엇을 계산했나

목표층 수온이 모두 있는 날에 연속 공백을 하나씩 만들었습니다. 공백 이외의 관측은 유지하고, 복원한 뒤의 하루 평균을 가리기 전 평균과 비교했습니다. **실제 공백의 정답을 복구했다는 실험이 아닙니다.**

최종 시험에서는 세 층 모두 하루 24시간 값이 있고 목표층의 하루 양끝 문맥도 있는 날짜를 사용합니다. 길이 `m`의 공백 시작점은 `0,m,2m,…<24`이며 모든 가능한 시작점이나 무작위 공백을 평가한 것은 아닙니다.

| 방법 | 공백·일평균 처리 |
|---|---|
| `remaining` | 남은 목표층 관측만 평균. 하루 전체 공백이면 NA |
| `temporal` | 공백 양끝 목표층 관측을 시간상 직선으로 연결 |
| `depth` | 같은 시각의 두 이웃층을 명목수심 비율로 결합 |
| `bridge` | 시간 보간에 이웃층 곡선의 양끝 직선 대비 변화량을 더함 |
| `selected` | 공백 밖 관측의 가상 공백 비교로 `temporal` 또는 `bridge` 선택 |

공백 양끝의 직선을 `L`, 두 이웃층의 수심 가중값을 `S`, 목표층을 `T`라고 하면 고정 보정식은 `L(T) + S − L(S)`입니다. 이 연구에서 사용하는 계산 명칭이며 수학적 방법의 최초 발명을 주장하지 않습니다.

최종 선택기는 공백 앞뒤 각각 7일에서 같은 길이의 비교를 각각 4개 이상 확보하고, 양쪽 모두 보정의 일평균 제곱오차가 작을 때만 보정합니다. 나머지는 시간 보간입니다. 학습 모델은 없지만 **남은 관측의 정답을 사용하는 국소 적응형 선택**입니다. 공백 이후 자료도 필요한 사후 처리입니다.

## 재현할 대상

공개 실행 경로는 **9단계의 마지막 Rottnest 배치 시험**입니다. 1~8단계는 결과와 조건을 읽는 역사 자료로 보존하며 모두를 새 환경에서 재실행했다고 주장하지 않습니다.

- [실행 입력 명세](config/site.json): 기기 280/278/284, 명목수심 33/44/55m, 평가 2024-12-12 이상~2025-04-16 미만 UTC.
- `frozen/method.py`, `frozen/selector.py`: 고정 방법.
- `expected/`: 이관 전 저장 집계와 대조할 값.
- `evidence/`: 앞선 연구에서 선별한 집계. 원자료·개별 수온 행은 배포하지 않습니다.
- [이관 계보](../../provenance/migration.json): 원본 상대 경로·SHA와 공개 파일·변환의 연결. 현재 이관의 해시는 당시 사전등록을 대신하지 않습니다.

```powershell
python -m pip install -e ".[replay]"
python -m research_playbook replay --case ocean-gap-repair --input-root "<공식 NetCDF를 둔 폴더>" --output "<새 결과 폴더>"
```

`input-root`에는 [Rottnest 원본](SOURCES.md#마지막-시험의-재계산-입력)을 준비합니다. 기존 출력에 덮어쓰지 않습니다. 이 재계산은 이미 관찰한 고정 결과의 확인이지 새 독립 검증이 아닙니다. 실제 이번 실행 범위는 [저장소 검수 기록](../../reports/VALIDATION.md)을 확인합니다.

## 가장 중요한 적용 경계

마지막 시험의 목표 ADCP는 이웃 계류와 **약 3.169km** 떨어져 있습니다. 같은 수직선의 프로필을 복원한 시험이 아니라 서로 떨어진 계류를 조합한 스트레스 시험입니다. 기기·위치·시기가 함께 바뀌어 실패 원인을 하나로 확정할 수 없습니다.

수온 공백을 다루는 데 재사용할 수 있는 것은 고정 수식만이 아니라 **같은 분모의 강한 기준선 비교, 숨긴 정답 차단, 실패와 fallback을 포함한 손익 분석**입니다. 그 절차는 [결측 자료 플레이북](../../playbooks/missing-data.md)에 정리했습니다.
