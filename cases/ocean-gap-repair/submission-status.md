# 대회 검토와 외부 제출 상태

**KDATA에는 제출하지 않았습니다.** 이 저장소는 공개 자료 연구의 보존·재사용 결과이며 대회 접수증이나 입상작이 아닙니다. 신청서 초안, 계산 완료, GitHub 공개, 외부 접수는 각각 다른 상태입니다.

## 시작 계기와 자료 분리

Ocean AI 본선 이후 다른 대회의 분석 레시피 제안 가능성을 검토했습니다. 사용자는 Ocean 대회에서 본선 진출 후 미수상이라고 확인했습니다. 이것만으로 새 대회의 중복 출품·권리 조건이 모두 충족되는 것은 아닙니다.

Ocean 배포 자료에는 재배포 제한이 있어 이 연구의 공개 입력으로 사용하지 않았습니다. 이후 KIOST 이어도 공개판과 IMOS 자료를 별도로 취득해, 모델 학습 없이 남은 평균·보간·보정·관측 기반 선택을 비교했습니다. 이전 대회 모델의 개선 수치나 발표 수치를 이번 공개 자료 연구 성과에 합치지 않았습니다.

## 확인한 것과 남은 조건

2026-10-21~22 작성한 로컬 검토 기록을 요약합니다. [KDATA 원 공고](https://kdata.or.kr/datahub/portal/support/board/10/48)의 현재 조건을 이 문서에서 새로 확정한 것은 아닙니다.

| 항목 | 기록된 상태 |
|---|---|
| 분석 레시피 제안 | 신청 문안 초안만 준비; 포털 저장·등록·제출 증거 없음 |
| Ocean 수상 여부 | 사용자가 본선 진출 후 미수상이라고 확인 |
| 자료 권리 | 공개 자료를 별도 취득; 기존 대회 자료 재사용 허가로 해석하지 않음 |
| 워크스튜디오 | 개인 로그인 후 가이드 접근에서 기업회원 재로그인 안내; 실제 분석 기능 이용·업로드 미확인 |
| 도구 사용 의무 | 공고와 신청 양식의 적용 범위가 모호해 운영기관 확인 필요 |
| 공모 분야 | 해양 수온 기록이 해당 수자원 분야 범위에 드는지 미확인 |
| 분석 기법 | 시간·수심 보간과 고정 보정, 관측 기반 선택; 학습 0회. 생성형 AI를 개발·검토 보조로 쓴 것과 계산 기법이 AI 모델이라는 주장은 구분 |
| 외부 반영 | 포털 접수·약관 동의·워크스튜디오 업로드·제출 메일 없음 |

## 다시 출품을 검토한다면

현재 공고의 자격·부문·자료 권리·필수 도구를 먼저 확인합니다. ‘학습하지 않았다’나 ‘공개 자료다’가 출품 자격의 대체 근거는 아닙니다. 이 연구에서 제출할 수 있는 좁은 주장은 [최종 결론](CONCLUSIONS.md) 범위입니다. 특정 지점 개선을 범용 복원 성능이나 기관 도입 효과로 확대하지 않습니다.

공개 코드·문서에 대한 승인과 대회 제출 승인은 별개입니다. 새 외부 제출이 생기면 대상, 제출본 식별자, 서버 반영 또는 접수증을 별도로 기록합니다.
