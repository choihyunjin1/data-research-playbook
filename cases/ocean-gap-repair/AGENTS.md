# Ocean 종료 연구의 보존 경계

이 지침은 `ocean-gap-repair`의 종료 연구·재현에만 적용한다. 다른 대회의 별도 연구를 금지하지 않는다.

- 기존 Ocean 저장소·원본 연구 폴더·원자료는 읽기 전용이다. 재실행은 새 출력 폴더를 쓴다.
- `frozen/`의 고정 방법·설정·기존 결과는 보존한다. 입출력 이관 수정과 방법 변경을 구분한다.
- 이 종료 연구를 재현하는 작업에서 새 학습·지점 탐색·임계값 조정을 하지 않는다. 후속 연구는 별도 프로젝트에서 시작하고 이미 본 자료를 새 독립 평가로 표시하지 않는다.
- 오류가 발견되면 당시 결과를 덮어쓰지 않는다. [기여 절차](../../CONTRIBUTING.md)에 따라 정정 근거와 별도 수정 버전을 연결한다.
